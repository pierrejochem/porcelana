Porcelana: accessible, mobile-ready React components on Radix UI

Porcelana is an open-source React component library built on Radix UI primitives and written in TypeScript. Components sit on porcelain-white, raised or recessed surfaces with cobalt-blue accents, and come in light and night themes.

Install

npm install @porcelana/ui @porcelana/icons, then import "@porcelana/ui/styles.css".

Components

  • Inputs: Button, Input, Textarea, Checkbox, Radio Group, Switch, Slider, Number Stepper, Select, Combobox, Date Picker, Calendar, Toggle Group
  • Overlays: Dialog, Alert Dialog, Popover, Dropdown Menu, Tooltip, InfoTip, Toast
  • Data and display: Data Table with sorting, search, selection and pagination; Card, Badge, Avatar, Progress, Skeleton, Accordion, Tabs, Breadcrumb, Pagination
  • Icons: 51 tree-shakable stroke icons in @porcelana/icons

Built for touch and assistive technology

  • Every control has a touch target of at least 44 × 44 px
  • Under 640 px wide, dialogs and menus become bottom sheets and tables become card lists
  • Keyboard support and ARIA from Radix, with every component tested by jest-axe
  • Supports reduced motion and Windows high-contrast mode, and text meets WCAG AA contrast in both themes
